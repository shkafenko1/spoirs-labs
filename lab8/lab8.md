# ЛР №8 — MPI: групповые и файловые операции

Расширение ЛР №7: **коллективные операции**, деление процессов на **группы**
и **файловый ввод-вывод** (MPI-IO).

## Состав

- `matmul_groups.py` — умножение матриц по группам с чтением/записью в файлы.
  Переиспользует `lab7/matmul.py` (парные операции — как базовый ориентир).

## Что реализовано

- **Коллективные операции**: `Bcast` (рассылка B), `Scatterv` (раздача полос A),
  `Gatherv` (сбор результата) вместо парных операций из ЛР №7.
- **Группы**: число групп задаётся `--groups`; процессы делятся на группы со
  **случайным** числом участников (через `MPI_Comm_split`). Каждая группа
  независимо умножает матрицы; замеряется время по каждой группе.
- **Сравнение**: время по группам сравнивается со временем парных операций
  (ЛР №7) и коллективных операций на всём мире.
- **Файловые операции (MPI-IO)**: исходные матрицы читаются из 2 общих файлов
  (`matrixA.bin`, `matrixB.bin`); каждый процесс читает свою полосу строк по
  своей координате (`Read_at_all`), результат пишется в файл своей группы
  (`group_<id>_C.bin`, `Write_at_all`).

## Требования

Те же, что для ЛР №7: MPI + `mpi4py` + `numpy` (см. `requirements.txt`).
Общие файлы должны лежать на файловой системе, доступной всем узлам
(например, NFS-каталог), — параметр `--dir`.

## Запуск

1. Подготовить общие входные файлы (один раз, без `mpirun`):

```bash
python3 lab8/matmul_groups.py --make-input --size 1200 --dir ./shared
```

2. Запустить умножение по группам:

```bash
# локально
mpirun --oversubscribe -np 8 python3 lab8/matmul_groups.py --size 1200 --groups 3 --dir ./shared

# на кластере (общий ./shared на всех узлах)
mpirun --hostfile hosts -np 12 python3 lab8/matmul_groups.py --size 2000 --groups 4 --dir ./shared
```

Если входных файлов нет, процесс 0 создаст их автоматически перед запуском.

Параметры:

- `--size N` — размер матрицы N×N;
- `--groups G` — число групп (процессы делятся случайно, каждая группа непуста);
- `--dir PATH` — каталог общих файлов.

Результат каждой группы — отдельный файл `group_<id>_C.bin` в каталоге `--dir`.

## Не обязательно

Запуск в кластерной среде через PBS Torque (`qsub` со скриптом, вызывающим
`mpirun`).
