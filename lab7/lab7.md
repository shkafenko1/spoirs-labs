# ЛР №7 — MPI: парные коммуникации, блокирующий и неблокирующий режим

Умножение матриц с использованием **парных (point-to-point)** операций MPI
в двух режимах: блокирующем (`Send`/`Recv`) и неблокирующем (`Isend`/`Irecv`).

## Состав

- `matmul.py` — программа умножения матриц на MPI (mpi4py + numpy).

## Что реализовано

- Матрица A делится на полосы строк; каждая полоса рассылается своему процессу
  парными операциями, матрица B рассылается целиком.
- **Блокирующий режим**: `Send`/`Recv`.
- **Неблокирующий режим**: `Isend`/`Irecv` — рассылка блоков совмещается с
  вычислением собственной доли строк на процессе 0 (перекрытие обмена и счёта).
- Замер времени каждого режима (`MPI.Wtime`) и проверка результата.

## Требования

- MPI-реализация (Open MPI или MPICH) и Python-пакеты `mpi4py`, `numpy`.

```bash
# macOS
brew install open-mpi
# Debian/Ubuntu
sudo apt install -y openmpi-bin libopenmpi-dev
# затем
pip install -r requirements.txt      # mpi4py, numpy
```

## Запуск

Локально (несколько процессов на одной машине):

```bash
mpirun -np 4 python3 lab7/matmul.py --size 1500 --mode both
```

Минимум на 3 машинах (файл `hosts` со списком узлов):

```bash
mpirun --hostfile hosts -np 6 python3 lab7/matmul.py --size 2500 --mode both
```

Больше процессов, чем ядер на машине — добавьте `--oversubscribe`:

```bash
mpirun --oversubscribe -np 16 python3 lab7/matmul.py --size 1500
```

Параметры:

- `--size N` — размер матрицы N×N. Для времени счёта ~10..50 с на BLAS-numpy
  берите крупный размер (порядка `--size 5000` и больше — зависит от машины).
- `--mode {blocking,nonblocking,both}` — какой режим замерять.

4. Преимущество асинхронных (неблокирующих) операций — перекрытие обмена и счёта.
