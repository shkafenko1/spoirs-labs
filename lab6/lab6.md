# ЛР №6 — широковещательный и многоадресный режимы: чат

Одноранговый (peer-to-peer) чат по UDP, использующий одновременно
**широковещательную** (broadcast) и **многоадресную** (multicast) передачу.

## Состав

- `netinfo.py` — автоопределение параметров интерфейса: IP, маска, broadcast.
- `chat.py` — сам чат: приём/отправка, обнаружение участников, команды.

## Что реализовано

- Приём и отправка сообщений **и по broadcast, и по multicast** (группа
  `239.255.13.37`).
- **Обнаружение участников**: периодические HELLO-маяки; команда `/who`
  выводит список IP запущенных приложений.
- **Самостоятельный выход** из multicast-группы (`/leave`) и возврат (`/join`)
  через `IP_DROP_MEMBERSHIP` / `IP_ADD_MEMBERSHIP`.
- **Принудительное игнорирование** хоста (`/ignore <ip>` / `/unignore <ip>`).
- **Автоопределение** IP, сетевой маски и широковещательного адреса.

## Запуск

На каждой машине в одной сети:

```bash
python3 lab6/chat.py --nick alice
python3 lab6/chat.py --nick bob --port 50000
```

Команды внутри чата:

| Команда          | Действие                                   |
|------------------|--------------------------------------------|
| `/who`           | список активных участников                  |
| `/net`           | параметры интерфейса (ip, маска, broadcast) |
| `/nick <имя>`    | сменить имя                                 |
| `/leave`         | выйти из multicast-группы                   |
| `/join`          | снова вступить в multicast-группу           |
| `/ignore <ip>`   | игнорировать хост                           |
| `/unignore <ip>` | снять игнорирование                         |
| `/quit`          | выход                                       |

Любой другой ввод рассылается всем участникам.

Только стандартная библиотека Python 3.

## Контрольные вопросы

1. Отличие многоадресной и широковещательной передачи.
2. Как формируется широковещательный адрес (IP OR инверсия маски).
3. Диапазоны multicast-адресов (224.0.0.0/4) и их назначение.
4. Механизмы ограничения области распространения (TTL / scope).
5. Область распространения широковещательных пакетов (одна подсеть).
